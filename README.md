Ein Bibliotheksverwaltungsprojekt bei dem man mit der Konsole neue Bücher anlegen kann, diese ausleihen und zurückgeben kann. Außerdem kann man diese auflisten und nach einem bestimmten Buchtitel suchen. Für jedes Buch wird außerdem noch gespeichert, ob dieses Buch ausgeliehen wurde und wenn ja von wem. Jedes Mal wenn sich etwas in der Bibliotheksverwaltung ändert wird eine .json Datei mit den ganzen Daten gespeichert. Und wenn das Hauptprogramm gestartet wird, wird diese .json Datei geladen und die Daten vom letzten Mal bleiben erhalten.
